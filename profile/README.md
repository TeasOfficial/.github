自 **2020** 年起，**Eh5の茶会** 就一直在折腾游戏服务器和它周边的一切：
运营 **CS:S 连跳（BunnyHop）社区**，编写 **SourceMod / bhoptimer** 插件，
顺手把配套的网站、QQ 机器人框架和桌面应用也一并做了。

> **18** 个原创公开项目 · **8** 个移植 / Fork · 覆盖 SourcePawn、Go、Rust、Vue、Java、Lua

| [**BHOP-Server-Simple-Logs**](https://github.com/TeasOfficial/BHOP-Server-Simple-Logs-) | 连跳服务器日志：聊天 / 换风格 / 换轨道 / 连接 / 地图完成 |
